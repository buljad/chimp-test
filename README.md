# 🐵 Тест Аюму // Monkey Memory Benchmark

Соревновательный интерактив для ИТ-стендов по мотивам знаменитого теста кратковременной памяти шимпанзе Аюму (Киотский университет).

---

## 🚀 Быстрый запуск

### Вариант 1: Python

```bash
python3 server.py
Вариант 2: Node.jsBashnode server.js
Открыть в браузере: http://localhost:3000🎮 Механика игрыУчастник вводит свой никнейм и пароль (до 20 символов).На сетке 5×5 появляются цифры (от 1 до $N$).Игрок запоминает их расположение.При клике на цифру 1 все оставшиеся ячейки превращаются в пустые карточки.Игрок восстанавливает цепочку по памяти: 2 ➔ 3 ➔ 4...Дается 3 жизни. Ошибка подсвечивает правильный порядок и сжигает одну жизнь.Победа в раунде открывает следующий уровень (+1 цифра).🏆 Скоринг и лидербордОсновной показатель: максимальное количество цифр, безошибочно собранных в цепочку.Тайбрейкер: суммарное чистое время кликов (при равенстве очков побеждает тот, кто кликал быстрее).Personal Best: лучший результат сохраняется в leaderboard.json и защищен паролем.
```
